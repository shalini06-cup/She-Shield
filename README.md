# She-Shield
A Women safety web application
**She Shield** is a dedicated wed application designed for women's safety and emergency assistance. It allow users to quickly access emergency services, share location details, submit safety reports, and access guidance even when navigating difficult situation or low-network conditions.

---
## 🌟 Key Features
* **Emergency Contacts & calling:** Quick access to call police and emergency helpline number.
* **Live Location Sharing:**Send current location details directly to emergency contacts.
* **Safety Reports & submission:**Dedicated pages ('reports.html' and 'report_details.html') to report public safety issues and view detailed information.
* **Safety Guidance & Suggestions:**Helpful tips and safety protocols to follow during critical situations.
* **History Management:**View previous reports and activity logs through the history section.
---
## 🛠️ Tech stack
* **Frontend:** HTML,CSS,JavaScript
* **Backend & Database:** Python (Flask), SQLite / Database File ('reports.db')

---
## 💡How It Helps
For example, if a women is in an isolated area or struggling with poor network connectivity, she can still use this web application to get immediate helpline numbers, send her location, submit safety issues, or offer suggestion to help others stating safe.
